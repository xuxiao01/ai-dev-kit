# 页面模式

先确定用户主要任务，再选择模式。以下文字线框只说明信息顺序，不是新增组件、接口或数据要求；未存在的操作、公告或指标不因示例自动增加。视觉尺寸参见 [视觉与交互规范](visual-guidelines.md)，代码定位参见 [组件指南](component-guide.md)。

## 1. 对象列表：识别、比较并操作对象

**适用条件**：需要扫描多个团队或配置，查看摘要后进入详情或执行已有操作。参考交易团队和团队配置列表。

**推荐结构**：标题和主操作 → 必要分组／数量 → 独立对象卡片。卡片顶部是名称、状态和详情入口，中部是关键摘要，底部按需放业务操作与危险操作。只有现有筛选和操作进入设计，不新增搜索、批量处理或指标。

```text
页面标题 · 简短说明                         [创建]
已有分组与数量（需要时）
┌ 对象名称 · 状态                        查看详情 ┐
│ 版本／执行模式等辅助信息                       │
│ 关键摘要或已有指标                             │
│ [业务操作]                      危险操作       │
└──────────────────────────────────────────────┘
下一张对象卡片
```

**窄屏变化**：名称允许换行，详情入口移到名称之后而非被挤掉；摘要逐步减少列数，操作换行。分组只在自身区域横向滚动，保持名称到操作的 DOM 阅读顺序。

**常见反例**：整页套大白卡，内部重复当前分组标题，再给每个对象套第二层卡片；信息不增反而占据更多空间。去掉重复容器，不删除业务状态。

## 2. 信息详情：理解一个对象及其组成

**适用条件**：需要核对单个配置或对象的结构、参数和关联资源。参考配置详情；创建预览与历史快照使用紧凑视图。

**推荐结构**：返回入口及唯一名称 → 版本、启用数、时间等元信息 → 分组内容 → 关联资源。长指令按需展开，不同时放大标题、层级统计和重复折叠标题。

```text
返回列表
唯一对象名称
版本 · 启用数 · 创建时间
内容区域标题与简短说明
角色分组与数量 ── 当前分组
智能体与职责       模型与工具       状态／查看指令
该条原始指令（按需展开）
关联团队与已有业务数据
```

**窄屏变化**：每条内容变为纵向信息块，保留字段含义与展开入口；角色标签局部滚动。长模型与指令换行，展开后不造成页面横向溢出。

**常见反例**：页面头部与白卡内重复同一名称，六列密集字段在手机整体缩小。改用信息分层和响应式行，不把完整详情的信息全部塞入 compact。

## 3. 设置表单：理解并修改偏好

**适用条件**：填写收件人、切换通知或修改其他已有设置。参考邮件设置，不涉及后端邮件正文。

**推荐结构**：标题与主要保存入口 → 按任务分区的字段 → 独立规则与记录。同一偏好表单保持同一提交边界；规则、测试发送等沿用独立动作，不伪装成主保存的一部分。

```text
设置页标题 · 简短说明                       [保存]
收件人／基础设置
字段标签  [适度宽度的输入框]
辅助说明与独立测试操作
账户摘要                  行情与新闻
每日摘要          [开关]  新闻摘要          [开关]
每周摘要          [开关]  发送时间与单位
独立规则表单与列表
最近记录及其局部状态
```

**窄屏变化**：两列分区变单列，标签与控件就近，单位和错误仍可读；长输入不横跨到屏外，记录表格只在自身滚动。保存入口保持可发现，不自行增加悬浮栏或自动保存。

**常见反例**：输入跨满大屏、开关远离标签，规则刷新又重置偏好草稿。调整字段宽度与同排对齐，并保留各动作原有状态隔离。

## 4. 数据总览：快速判断当前情况

**适用条件**：先看账户整体状态，再进入已有明细或操作。参考 Overview 的标题、公告、指标和区域组织，不照搬其全部历史装饰。

**推荐结构**：标题及必要的已有公告 → 核心指标 → 明细和快捷入口。只突出真实已提供的指标，不为了填满一行虚构汇总、图表或趋势。

```text
总览标题 · 账户相关辅助信息
已有公告条（适用时）
核心指标    核心指标    核心指标
受影响区域的错误／旧数据说明（失败时）
明细与已有快捷入口
团队区域或其他成功加载的内容
```

**窄屏变化**：指标逐步减少列数，数值及单位完整；按任务重要性保持顺序。局部失败留在受影响区域，其他成功数据仍能使用。

**常见反例**：任何接口失败就用整页错误盖掉成功区域，或为了看起来完整把未知资产写成零。保留局部状态和真实数据含义，不借此改变估值或刷新策略。

## 选择与例外

混合页面按主要任务选模式，独立区域可组合其他模式；不为套模板新增功能。设计说明用简短文字点明：所选模式、主要操作、最重要的信息，以及为什么需要偏离推荐基线。只改局部控件时无需重排整个页面。
