# 科研与技术绘图

先弄清楚这张图要回答的问题、读者在哪里看、需要哪种可编辑文件。根据代码、论文、实验记录或用户确认的流程建立结构。参考图用于选择版式和配色。

## 选择画法

| 要说明的内容 | 画法 | 可编辑模板 |
| --- | --- | --- |
| 特征如何逐层变换 | 薄片层图，主干横向，残差就近绕行 | [源图](assets/network-layers.drawio) · [预览](assets/network-layers.png) |
| 一个模块怎么算 | 彩色算子展开图，分支对齐，合流清楚 | [源图](assets/operator-flow.drawio) · [预览](assets/operator-flow.png) |
| 系统或模型如何分支与汇合 | 总体架构图，区分主路径和辅助路径 | [源图](assets/architecture.drawio) · [预览](assets/architecture.png) |
| 谁先调用、谁回调、两个请求怎样交错 | 时序图，按参与方分列，从上到下读 | [源图](assets/concurrent-save.drawio) · [预览](assets/concurrent-save.png) |

- 画科研网络或数据几何关系时，读[网络图型与科研语义](references/diagram-styles.md)。区分原有结构、新增结构、训练监督和实测结果。真实图像叠加标记时，按用户提供的图像与坐标重算裁剪和缩放。
- 画架构、调用链或并发时序时，读[技术文章配图](references/article-diagrams.md)。先明确参与方、方向、先后顺序和需要标出的状态变化，在手机文章宽度检查名称、箭头和关键数值。
- 出图、插入演示文稿或制作 WPS 可编辑表图时，读[导出与演示文稿验收](references/ppt-and-exports.md)。答辩图看插入整页后的实际字号，论文图按最终栏宽检查。

## 制作和交付

1. 用一句话说清这张图要解释什么。先布主线，再放分支、回路和图例。一张图只讲一个层次，复杂机制另做展开图。
2. 将对应模板复制到任务目录。节点、标签和连接线用 draw.io 原生对象。用短连线、对齐和精简措辞留出空间，颜色和线型各自表达明确的含义。示例的结构和数值仅用于演示。
3. 默认交付可编辑的 `.drawio` 源文件、高清 PNG 和 SVG。可用 `scripts/export_drawio.py` 导出。只有任务要求更新 PPT 时才改演示文稿，实验表图需要在 WPS 编辑时交付原生 PPTX 对象。
4. 对照来源检查输入输出、分叉汇合、连接方向、公式、数字和图例。用最终展示尺寸预览。保留影响结论的单位、条件和数据来源。
