# 导出与演示文稿验收

## 导出源图

使用本机已安装的 draw.io 桌面程序。脚本先检查指定的 `--drawio`，省略时查找 `DRAWIO_BIN`、macOS 应用或 PATH。以下命令从 Skill 目录运行，也可以用脚本的绝对路径。

```bash
python3 scripts/export_drawio.py /path/to/figure.drawio --out-dir /path/to/export --width 4000
```

`--page` 从 1 开始，默认导出第一页。脚本先在临时目录生成并检查 PNG、SVG，再写入目标目录，输出尺寸、文件路径和 SVG 诊断。需要替换已有导出时显式用 `--overwrite`。

SVG 的 HTML 标签、内嵌照片或外链资源可能影响不同阅读器的显示。脚本保留没有有效 SVG 回退的 HTML 标签，并提示检查实际显示。含照片的 WPS 几何图优先插入已核对的高清 PNG，源图和 SVG 留作编辑与交付。若 SVG 含外链图，先让源图包含所需素材再重新导出。

## 字号与整页排版

先确定图在最终 PPT 或论文里的展示宽度，再排模块。投屏时可将核心模块和公式以 22–28 pt 为起点，主要图例以 18–22 pt 为起点，按实际模板和内容调整。中文说明可以用 PPT 原生文本，贴近所解释的模块。短英文算子保持统一字号。

```text
最终字号（pt）≈ 源图字号（px）× 图片在 PPT 中的宽度（pt）÷ 源图宽度（px）
```

例如源图宽 1440 px，插入后宽 12 英寸（864 pt），源图 24 px 的字约为 14.4 pt。改变导出分辨率不会改变这个比例。字小就先缩短空连线、去掉重复标签或把细节拆到另一张图。期刊按最终栏宽检查，答辩按整页和实际放映尺寸检查。

## WPS 可编辑表格和图表

- 按实验记录制作原生 PPTX 表格和图表。三线表仅留表顶、表头下方、表底三线，条件列左对齐，数字列精度一致。写清单位和条件，区分百分比与百分点。
- 图表内嵌可编辑数据工作簿。表用于查准确值，图用于看趋势或分布。柱状图从零起轴。图表标签应和数据系列对应，必要时把标签字号写到系列级 `c:ser/c:dLbls/c:txPr`，再核对 WPS 实际显示。
- 核对表格单元格、内嵌数据、标签、符号与精度。若只有示例数据，在图或图注里标明。

## 替换目标页

保存可恢复副本，按演示文稿顺序定位目标页。保留现有母版、标题和其他页面，确认目标页引用的媒体是本次定稿。先看整页渲染，再在用户使用的 WPS 或 PowerPoint 中重新打开核对。如果只完成了文件或离线渲染检查，交代实际验证范围。
